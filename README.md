# Agent Papers feedback

This is the public review queue for [Agent Papers](https://agentpapers.dev) registry submissions and corrections.

Use the [structured submission form](https://agentpapers.dev/submit) to prepare an issue. Include only public source URLs and registry facts. Do not include private, confidential, or personal information.

GitHub authentication and abuse controls limit automated spam. Maintainers review issues against the published [curation methodology](https://agentpapers.dev/methodology). Closing an issue records its review outcome. Issues remain available as public audit history unless removal is needed for privacy or safety.
